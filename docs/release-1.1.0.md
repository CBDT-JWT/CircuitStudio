# Circuit Studio 1.1.0

- New Mac documents start with a blank canvas.
- Added document-persistent Schematic and Illustration modes.
- Illustration includes input/output/bidirectional ports, summing junctions, database, I/O and preparation shapes; arrows remain decorative rather than electrical connections.
- Simulation runs only in Schematic, including SPICE export.
- Simulation results can open in a native Mac tab or separate window. Open results retain a snapshot while the source document changes.
- Added a universal Apple Silicon/Intel DMG with drag-to-Applications installation.
- Published the static marketing site, source code and MIT license.

Requires macOS 26+. The direct-download build is ad-hoc signed and not Apple-notarized. See the release checksum and metadata files for exact binary information.
