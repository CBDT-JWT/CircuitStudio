# Visual assets

`glass-sheets.webp` is original campaign artwork generated with the built-in
ImageGen tool; the full-resolution source is `glass-sheets.png`.

Prompt: Create a premium studio photograph-like 3D image of three thin translucent
frosted glass drawing sheets floating in parallel, etched with sparse engineering
circuit lines and block diagram paths, and small teal connection nodes. Very pale
cool gray surface, soft long shadows, tactile glass edges, orthographic diagonal
top-down camera, landscape 3:2. Restrained deep teal, off-white and pale gray.
No text, branding, application UI, laptop, watermark, or purple gradients.

`schematic`, `illustration`, and `blank` are captures of the actual native app.
`waveform` is a detail from the real application screenshot.
`system-diagram` is exported by CircuitCore's own drawing engine.
The icon is the application's existing icon asset.
