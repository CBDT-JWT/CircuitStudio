Circuit Studio

Support / 使用支持

Start drawing / 开始绘图

Create a document, insert a component from Library, then use Wire to connect its terminals. Edit values in Inspector. / 新建文档，从 Library 放置元件，再用 Wire 连接针脚，在 Inspector 修改参数。

Simulation / 本地仿真

Choose a circuit template, select OP, DC, AC or TRAN, then Run. Models and SPICE analyses run on your device. A floating node or missing model should be corrected in the diagram or model library. / 选择电路模板和分析类型后点击 Run，仿真在设备上运行。浮空节点或缺失模型需要在电路或模型库中修正。

Export / 导出

Use Export for vector PDF/SVG, raster images, CircuitikZ or SPICE. Save editable .circuit documents for later changes. / 使用 Export 导出图片、矢量图与代码，并保存 .circuit 文档以继续编辑。

Files / 文档

Choose local storage or iCloud Drive in the system document interface. Cloud synchronization requires your Apple account and Apple’s iCloud service. / 在系统文档界面选择本地或 iCloud Drive；云同步由 Apple 的 iCloud 服务处理。

Contact / 联系支持

Contact cbdt@weitao-jiang.cn. When reporting a problem, include your device, operating-system version, app version and steps to reproduce. Attach a minimal non-confidential circuit only if needed. / 联系邮箱：cbdt@weitao-jiang.cn。反馈问题时请说明设备、系统版本、应用版本和复现步骤；需要附件时请使用不含保密信息的最小示例。
