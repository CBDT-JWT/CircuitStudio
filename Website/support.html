Circuit Studio 1.3.8 官网 Mac 版使用指南。

安装 Mac 版

  1. 从官网下载通用 DMG 安装包，打开后把 Circuit Studio 拖进「应用程序」。
  2. 从「应用程序」打开 Circuit Studio。支持 macOS 26 或更新版本、Apple Silicon 与 Intel，无需另外安装仿真程序。
  3. 当前 1.3.8 安装包使用 Developer ID Application 签名，已通过 Apple 公证。如果系统提示无法验证软件，请先核对下载来源，参阅 Apple 安全打开 App 的说明。

放置与绘图

从元件库选择元件，点击画布放置。文字、矩形、直线和其他标注使用十字准星定位。直线、矩形、圆形等图形先点击起点，再点击终点，也可以直接拖动；Esc 可取消。文字使用 T，电气连线使用 W。

按 P 放置单元引脚。新引脚默认没有命名网络，也不显示网络名称；可以在参数里设置需要的网络名。

极性标注先单击 + 端，再单击 − 端完成；也支持从 + 端拖到 − 端松开。文字、+ 和 − 在任意方向、旋转及镜像后都保持水平。选中后可分别拖动两端调整间距和方向；双击文字可编辑标注。

文本框可以在画布任意位置放置和拖动，不吸附网格。默认显示编辑边框，可在「编辑 → 文本框边框」或文字编辑工具栏关闭。应用内截图、复制图片及导出均不含编辑边框；使用系统截屏时请先关闭边框。

颜色与线型

选择一个对象或框选多个对象后，在右上角「选区样式」中设置颜色与实线、虚线。也可点击底部「样式」或「编辑 → 选区样式…」重新打开面板。支持元件、图形和导线批量设置；颜色可用取色器或十六进制值，点击「默认」恢复默认颜色。单根导线和元件的参数面板也提供颜色与线型。

双击文字可单独修改文字颜色，包括独立文本框、元件标号、元件数值及极性标注。选区整体改色时，所选元件的文字会跟随新颜色。样式支持撤销、保存、复制粘贴和图片导出，不改变电气连接与仿真参数。

复制与导出

框选对象后按 ⌘C，默认复制 SVG 矢量图。在 Circuit Studio 内按 ⌘V，仍是可以继续编辑的元件和连线；其他应用需要支持 SVG 剪贴板。需要位图时可使用「复制 PNG」。导出菜单提供 SVG、PDF、PNG 等格式。请保存可编辑工程，以便继续修改。

本地仿真

连接元件端子后打开仿真设置，选择工作点、直流扫描、交流或瞬态分析。可以从电路模板开始。仿真通过本机 ngspice 运行；浮空节点和缺失模型需要先修正。每次仿真结果保留当次快照。

应用内更新

官网版通过本网站的签名更新源检查新版，自动检查开启时会提示可用更新。也可以在应用菜单选择「检查更新…」，按提示下载安装并重新启动。更新器会验证签名，请先保存正在编辑的文档。App Store 与 TestFlight 版本通过各自商店更新。

使用较早的官网旧版时，请先从本网站下载安装当前版本，以启用新的官网更新源。

常用快捷键

W 连线 · T 文字 · P 单元引脚 · R 旋转 · X / Y 镜像 · F 适应画布 · Esc 结束工具。复制、粘贴、撤销和重做使用 Mac 的标准快捷键。

连接本机 Codex

在 Mac 版 CircuitAI 抽屉的提供方菜单里选「本机 Codex」。复制启动命令，到终端运行并保持窗口开启，然后把终端里的连接码粘贴回 App。需要安装并登录支持 WebSocket 连接的 Codex CLI。停止终端进程后，下次启动会生成新连接码。
